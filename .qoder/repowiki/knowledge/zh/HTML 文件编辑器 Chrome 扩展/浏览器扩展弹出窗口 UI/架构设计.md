由三个平铺文件组成：popup.html 提供头部（logo/标题/版本）、状态指示区、操作按钮（开始/停止编辑、保存）以及使用说明与权限提示；popup.css 使用 BEM 风格类名（header/status/actions/section/btn-*）定义固定宽度 380px 的弹出面板样式；popup.js 采用 IIFE + 'use strict' 自包含脚本，通过 chrome.tabs.query 获取当前活动标签并判断 URL 是否以 file:// 开头，再通过 chrome.tabs.sendMessage 向 content script 发送 {type: 'getStatus'|'toggleEdit'|'save'} 消息来同步编辑状态，根据响应更新 #status 文本、#dot 的 active/inactive 类以及按钮禁用状态。该模块仅作为用户入口层，不直接操作 DOM 编辑器，所有实际编辑逻辑委托给 content script。
